[1]CoRL 2026 Workshop: Pretrain to Adapt
Amortized Low-Rank Adaptation for Model-Based Reinforcement Learning
Fernando Palafox, David Fridovich-Keil

The problem

World models trained on one set of environments break when the dynamics or embodiment change at test time. We want to adapt them to a new environment from only a few seconds of data.

Our solution

CLAW jointly pretrains a base world model and a hypernetwork across many environments. At test time the base model stays frozen, and the hypernetwork turns a short context of data into LoRA adapters in a single forward pass, with no gradient steps. On locomotion and manipulation tasks with varying dynamics and embodiments, it beats gradient-based adaptation and in-context learning, and it avoids overfitting when data is scarce.

[2]RSS 2026
Simulation Distillation: Pretraining World Models in Simulation for Rapid Real-World Adaptation
Jacob Levy, Tyler Westenbroek, Kevin Huang, Fernando Palafox, Patrick Yin, Shayegan Omidshafiei, Dong-Ki Kim, Abhishek Gupta, David Fridovich-Keil

The problem

Fine-tuning a sim-trained policy on a real robot with RL struggles with exploration and long-horizon credit assignment when real data is scarce.

Our solution

Simulation Distillation transfers reward and value functions from simulation into a latent world model before deployment. On the real robot only the dynamics are fine-tuned, so adaptation reduces to short-horizon system identification paired with online planning. On manipulation and locomotion tasks it beats prior sim-to-real methods in both data efficiency and final performance.

[3]Under review
Generalized Information Gathering Under Dynamics Uncertainty
Fernando Palafox, Jingqi Li, Jesse Milzman, David Fridovich-Keil

The problem

Gathering information on purpose speeds up learning the dynamics of an unknown system. But existing methods derive a bespoke information-gathering cost for each combination of dynamics model, belief update, observation model, and planner.

Our solution

We expose the causal dependencies between parameters, beliefs, and controls, and derive a general cost based on Massey's directed information that assumes only Markov dynamics with additive noise. The mutual-information cost from prior work is a special case, and we connect it to information gain in linearized Bayesian estimation. Experiments cover linear, nonlinear, and multi-agent systems.

[4]JMLMC 2026
Data-Driven Modeling and Correction of Vehicle Dynamics
Nguyen Ly, Caroline Tatsuoka, Jai Nagaraj, Jacob Levy, Fernando Palafox, David Fridovich-Keil, Hannah Lu

The problem

Simplified vehicle models like the unicycle and bicycle are fast but lose accuracy in aggressive, high-speed driving, and the high-fidelity data needed to correct them is expensive.

Our solution

We use two data-efficient methods. DRIPS lifts the dynamics into a linear space with dynamic mode decomposition and fits cheap surrogate models there, which works well for moderately complex models. For strongly nonlinear models we use flow map learning: a neural network pretrained on a simple prior model, with its last layers fine-tuned on real data. We validate both on several vehicle models, including real data from an NVIDIA JetRacer.

[5]TMLR 2025
A Player Selection Network for Scalable Game-Theoretic Prediction and Planning
Tianyu Qiu, Eric Ouano, Fernando Palafox, Christian Ellis, David Fridovich-Keil

The problem

Game-theoretic planners model multi-agent interaction well but scale poorly. Games with hundreds of players are too slow to solve in real time.

Our solution

A Player Selection Network looks at past trajectories and outputs a mask that keeps only the most influential agents, so the ego agent solves a much smaller game. The network is trained end-to-end through a differentiable game solver, with no hand-tuned heuristics. It cuts runtime by 10x, keeps trajectories safe and smooth, and transfers to real-world data without fine-tuning.

[6]AAMAS 2025
Smooth Information Gathering in Two-Player Noncooperative Games
Fernando Palafox, Jesse Milzman, Dong Ho Lee, Ryan Park, David Fridovich-Keil

The problem

In a two-player game, one player is uncertain about the other's costs but can spend resources beforehand to learn about them. Existing models of this setting don't let that allocation vary smoothly.

Our solution

We model it as a two-stage game: first the uncertain player allocates information-gathering resources, which smoothly change the signal it receives; then both players act on that signal. We give conditions under which the gradient of the cost with respect to the allocation is well defined, which leads to a gradient-based solver. We apply it to a tower-defense variant of Colonel Blotto with uncertain battlefield values.

[7]AAS/AIAA 2024
Learning Hyperplanes for Multi-Agent Collision Avoidance in Space
Fernando Palafox, Yue Yu, David Fridovich-Keil

The problem

Robots with conflicting objectives still have to avoid colliding with each other, and hand-picking collision-avoidance constraints easily makes the planning problem infeasible.

Our solution

We enforce collision avoidance in a game-theoretic planner with rotating hyperplane constraints: separating planes that rotate around a keep-out zone centered on each robot. We learn the hyperplane parameters from expert trajectories, such as recordings of human operators, by solving an inverse game for the parameters whose equilibrium best matches the expert. We demonstrate it on spacecraft using the Hill-Clohessy-Wiltshire equations for relative orbital motion.

[8]CDC 2023
Scenario-Game ADMM: A Parallelized Scenario-Based Solver for Stochastic Noncooperative Games
Jingqi Li, Chih-Yuan Chiu, Lasse Peters, Fernando Palafox, Mustafa Karabag, Javier Alonso-Mora, Somayeh Sojoudi, Claire Tomlin, David Fridovich-Keil

The problem

Stochastic games capture uncertainty in multi-agent interaction, but they get expensive to solve as the number of uncertainty scenarios grows.

Our solution

We approximate the uncertainty with a set of scenarios and use ADMM to split the resulting game into per-scenario subproblems that are solved in parallel, which greatly speeds up computing solutions. Joint work with collaborators at UC Berkeley and TU Delft.

[9]ION ITM 2022
A Collection of SDRs for Global Navigation Satellite Systems (GNSS)
Joan Bernabeu, Fernando Palafox, Yafeng Li, Dennis M. Akos

The problem

Researchers working on satellite navigation need open-source receivers they can modify, along with a clear picture of how well each one performs.

Our solution

We introduce the latest version of an open-source collection of software-defined receivers for systems including GPS, GLONASS, and Galileo, and describe its structure and the changes made to improve each code base. Each receiver goes through an extensive test campaign covering signal acquisition, tracking, navigation data demodulation, and positioning accuracy. Work done at the RF & SatNav Lab at CU Boulder with Dennis Akos.

[10]ION GNSS+ 2021
Developing a Low-Cost, High Performance, SDR-Based Local Positioning System
Fernando Palafox, Lyndsay Ruane, Scott Palo, Dennis Akos

The problem

Positioning, navigation, and timing usually depend on GNSS, which is unavailable in GNSS-denied areas.

Our solution

We built an alternative from software-defined radios: a navigation signal modeled on GPS L1C, broadcast from a network of SDR transmitters. A moving receiver running a MATLAB software receiver successfully estimated changes in range to each transmitter.
